# Okat.kg — обеды на работу

Прототип платформы, где кухни, столовые и кафе Бишкека публикуют меню на день, а сотрудники офисов
заказывают себе обед с утра. Заявка становится заказом после подтверждения кухней; доставляет сама кухня.

**Сайт:** https://kutya001.github.io/Okat.kg/

Это статический сайт без сборки и без сервера. Все данные демонстрационные, живут в памяти страницы
и сбрасываются при перезагрузке.

## Что уже есть

**Клиент**

- «Заведения»: лента кухонь, столовых, кафе и ресторанов; блюда каждого листаются вбок и добавляются в корзину прямо из карточки;
- «Блюда»: лента по категориям и видам блюд — у плова, лагмана или супа видны предложения всех заведений с ценой, рейтингом и расстоянием; поиск и сортировка;
- карточка блюда: описание, калории, белки, жиры, углеводы, метки пользы;
- меню заведения, корзина, заявка, статусы заказа;
- оплата переводом: реквизиты кухни и чек, который клиент прикрепляет к заявке;
- статистика: сколько заказов и денег, калории по дням, белки, жиры и углеводы за обед, любимые заведения и блюда;
- счётчик «сколько человек с моей точки уже заказали» и карта с заведениями.

**Кухня**

- сводка дня: заявки, заказы, выручка, себестоимость, прибыль;
- заказы доской (с перетаскиванием) и таблицей;
- проверка чека: заявку с переводом принимают только после просмотра чека, неподходящий чек возвращают клиенту;
- меню на каждый день отдельным документом: свои цены, лимиты, время приёма и минимальная сумма заказа, копирование на другой день;
- каталог блюд: себестоимость, фото, описание, пищевая ценность, метки, вид блюда; отчёт по выручке, настройки заведения;
- клиенты: кто, когда и что заказывал, постоянные и новые, поиск, история каждого клиента;
- левая панель сворачивается до значков, выбор запоминается в браузере.

Переключатель «Клиент / Кухня» и выбор времени вверху экрана — служебная панель прототипа.

## Запуск

Сборка не нужна.

```bash
# вариант 1: открыть index.html в браузере двойным кликом
# вариант 2: локальный сервер
python3 -m http.server 8080   # http://localhost:8080
```

### GitHub Pages

Сайт раздаётся прямо из ветки `main`: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
Все пути в проекте относительные, поэтому сайт одинаково работает в подпапке
`kutya001.github.io/Okat.kg/` и на собственном домене.

```
  vendor/leaflet/       библиотека карты

  demo.css              служебная панель прототипа
  components.css        кнопки, метки, карточки
  client.css            экраны клиента
  map.css  sheets.css   карта и нижние шторки
  kitchen.css           кабинет кухни
  responsive.css        планшет и компьютер (подключается последним)
js/
  core/                 помощники, состояние, отрисовка, обновление экрана на месте, анимации,
                        история браузера, общие действия
  data/                 справочники, заведения, блюда, меню, люди, заказы, демо-данные,

  client/               экраны клиента
  kitchen/              кабинет кухни
  main.js               запуск
tests/                  автотесты на Playwright
```

## Как устроен код

- **Без модулей и сборщика.** Файлы в `js/` — обычные скрипты с общей областью видимости. Порядок
  загрузки задан в `index.html`: сначала данные, потом ядро, потом экраны, в конце `main.js`.
- **Состояние** — один объект `S` (`js/core/state.js`). После любого изменения вызывается `render()`
  (`js/core/app.js`): он собирает разметку экрана заново, а `js/core/morph.js` меняет в странице только
  то, что отличается. Поэтому картинки не мигают, прокрутка и фокус остаются на месте, а переходы CSS
  срабатывают сами.
- **Анимации** (`js/core/motion.js`) — только для того, что появилось в ответ на действие: новый экран,
  счётчик порций, корзина, карточка заказа. Настройка «уменьшить движение» в системе их отключает.
- **Действия** привязаны через атрибуты: `data-act="имя"` вызывает `A.имя` по нажатию,
  `data-chg` — `C.имя` при изменении поля, `data-inp` — `I.имя` при вводе.
- **Шторки** — функции в `SHEETS`; открыть: `S.sheet = { type: 'имя' }` и `render()`.
- **Кнопка «Назад»** (`js/core/history.js`): каждый экран и шторка — запись в истории браузера.
- **Карта** (`js/map/`): Leaflet и тайлы OpenStreetMap; если серверы карты недоступны, рисуется схема.

Новый экран — это файл в `js/client/` или `js/kitchen/` и строка `<script>` в `index.html`.

При выкладке новой версии увеличьте номер `?v=` в адресах файлов в `index.html` (везде одинаковый):
GitHub Pages держит файлы в кеше браузера около десяти минут, и без этого старые файлы могут смешаться с новыми.

## Тесты

```bash
npm install
npx playwright install chromium
npm test
```

Тесты открывают `index.html` из репозитория. Другой адрес: `OKAT_URL=http://localhost:8080/ npm test`.

## Чего пока нет

Сервера, входа по телефону, приёма оплаты и уведомлений. Чеки и фото живут только в памяти страницы.
Координаты заведений, калории и БЖУ блюд, клиенты и история заказов условные и создаются при загрузке.
