# Okat.kg — обеды на работу

Прототип платформы, где кухни, столовые и кафе Бишкека публикуют меню на день, а сотрудники офисов
заказывают себе обед с утра. Заявка становится заказом после подтверждения кухней; доставляет сама кухня.

**Сайт:** https://kutya001.github.io/Okat.kg/

Это статический сайт без сборки и без сервера. Все данные демонстрационные, живут в памяти страницы
и сбрасываются при перезагрузке.

## Что уже есть

**Клиент**

- лента заведений с меню на сегодня, фильтр по типу;
- меню заведения, корзина, заявка, статусы заказа;
- счётчик «сколько человек с моей точки уже заказали» и карта с заведениями.

**Кухня**

- сводка дня: заявки, заказы, выручка, себестоимость, прибыль;
- заказы доской (с перетаскиванием) и таблицей;
- меню на каждый день отдельным документом: свои цены, лимиты и время приёма, копирование на другой день;
- каталог блюд с себестоимостью и фото, отчёт по выручке, настройки заведения.

Переключатель «Клиент / Кухня» и выбор времени вверху экрана — служебная панель прототипа.

## Запуск

Сборка не нужна.

```bash
# вариант 1: открыть index.html в браузере двойным кликом
# вариант 2: локальный сервер
python3 -m http.server 8080   # http://localhost:8080
```

### GitHub Pages

Сайт раздаётся прямо из ветки `main`: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
Все пути в проекте относительные, поэтому сайт одинаково работает в подпапке
`kutya001.github.io/Okat.kg/` и на собственном домене.

```
index.html              разметка страницы и порядок подключения файлов
404.html                возврат на главную с несуществующего адреса
manifest.webmanifest    установка на телефон как приложения
assets/
  fonts/                Golos Text
  icons/                иконки сайта и приложения
  vendor/leaflet/       библиотека карты
css/
  fonts.css  tokens.css цвета, шрифт, сброс
  demo.css              служебная панель прототипа
  components.css        кнопки, метки, карточки
  client.css            экраны клиента
  map.css  sheets.css   карта и нижние шторки
  kitchen.css           кабинет кухни
  responsive.css        планшет и компьютер (подключается последним)
js/
  core/                 помощники, состояние, отрисовка, история браузера, общие действия
  data/                 справочники, заведения, блюда, меню, заказы, демо-данные
  map/                  метки, настоящая карта, запасная схема
  client/               экраны клиента
  kitchen/              кабинет кухни
  main.js               запуск
tests/                  автотесты на Playwright
```

## Как устроен код

- **Без модулей и сборщика.** Файлы в `js/` — обычные скрипты с общей областью видимости. Порядок
  загрузки задан в `index.html`: сначала данные, потом ядро, потом экраны, в конце `main.js`.
- **Состояние** — один объект `S` (`js/core/state.js`). После любого изменения вызывается `render()`
  (`js/core/app.js`), который заново рисует экран.
- **Действия** привязаны через атрибуты: `data-act="имя"` вызывает `A.имя` по нажатию,
  `data-chg` — `C.имя` при изменении поля, `data-inp` — `I.имя` при вводе.
- **Шторки** — функции в `SHEETS`; открыть: `S.sheet = { type: 'имя' }` и `render()`.
- **Кнопка «Назад»** (`js/core/history.js`): каждый экран и шторка — запись в истории браузера.
- **Карта** (`js/map/`): Leaflet и тайлы OpenStreetMap; если серверы карты недоступны, рисуется схема.

Новый экран — это файл в `js/client/` или `js/kitchen/` и строка `<script>` в `index.html`.

## Тесты

```bash
npm install
npx playwright install chromium
npm test
```

Тесты открывают `index.html` из репозитория. Другой адрес: `OKAT_URL=http://localhost:8080/ npm test`.

## Чего пока нет

Сервера, входа по телефону, приёма оплаты и уведомлений. Координаты заведений условные.
